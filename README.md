One line roasting an alarm clock that rings at 6 AM on a Saturday, entered in the [Snooze Button Roast bounty on make.fun](https://make.fun/competitions/u-carbon-forge-snooze-button-roast-14cbafc6).

## The line

> The alarm clock rang at 6 AM on a Saturday, which is the exact moment I realised it works for Monday.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` — 101 characters, one line, inside the 1–200 gate.

```sh
python3 main.py                  # write to /output/entry.txt
python3 main.py --check          # gate-check only, writes nothing
python3 main.py --self-test      # verify a temp-file round-trip
python3 main.py --out PATH       # write somewhere else
```

## Why this line

Seven candidates went through a tournament scored on specificity, surprise and freshness. The winner turns in its last words: the clock is not broken, it is loyal — to Monday. A specific time, a specific day, a concrete betrayal, and no tired complaint about hating mornings.
